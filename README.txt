LOSTFOUND SEKOLAH - WEB ADMIN

1. Copy folder lostfound_admin ke:
   C:\xampp\htdocs\lostfound_admin

2. Pastikan Apache dan MySQL aktif.

3. Pastikan database:
   lost_found
   table: barang

4. Buka:
   http://localhost/lostfound_admin/login.php

5. Login demo:
   Username: Admin
   Password: 12345

6. Fitur:
   - Dashboard rekap total barang
   - Pencarian nama/lokasi/keterangan
   - Foto barang
   - Cetak rekap
   - Export Excel (.xls)

Catatan foto:
Folder foto diasumsikan tersedia di:
C:\xampp\htdocs\lost_found_api\uploads\
Jika folder backend kamu berbeda, ubah path gambar di index.php.
